# MotionLab

MotionLab은 기구 설계자를 위한 모션 설계 보조 플랫폼입니다. 설계 초기 단계에서 필요한 모터, 감속기, 토크 계산, 자료 관리를 한곳에서 정리하는 것을 목표로 합니다.

## Core workflow

- 모터 검색
- 감속기 계산
- RMS 토크 계산
- 도면/스펙 링크 관리
- PDF 리포트 생성 예정

## Direction

포털에서는 MotionLab의 소개와 서비스 링크만 제공합니다. 실제 MotionLab 기능 코드는 `motion.dadacloudlab.com`에서 독립적으로 운영합니다.
